# Impact notes (internal)

project's impact, and what to eventually report on the public Impact tab.

- CSV downloads

2. Collect feedback via the in-app Feedback form.
3. Improve the tool based on feedback.
4. Report the numbers above on the public Impact tab once they can be
   calculated.
